# Kristiansand Tannlegevakt – demo

Statisk forhåndsvisning (HTML/CSS/JS) av forsiden og tjenestesiden «Akutt tannverk».

## Publisere på GitHub Pages
1. Last opp alle filene i denne mappen til roten av et GitHub-repo (inkl. `assets/`, `.nojekyll` og `404.html`).
2. Settings → Pages → Source: «Deploy from a branch», branch `main`, mappe `/ (root)`.
3. Siden blir tilgjengelig på `https://<brukernavn>.github.io/<repo>/`.

Sider som ikke er laget ennå, viser `404.html` («Denne siden kommer snart»).
Priser, telefonnummer og e-post er midlertidige og må byttes før lansering.
